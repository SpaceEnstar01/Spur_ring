# 优化任务响应速度并接通网页直接生图

日期：2026-11-01。范围：仅 V2 本地网页、工具适配与开发记录；未修改原工程、上游 Harness 或邮件发送模块。

## 用户反馈与原因

用户希望任务直接得到结果。请求“生成一张库里打篮球的图片”时，网页 Agent 没有接入生图工具，却长篇输出平台推荐、提示词、去标识建议和法律讨论，最后还让用户自行将 SVG 文本改后缀。这不符合用户目标。

共享配置已有 `SPUR_IMAGE_MODEL=Tongyi-MAI/Z-Image-Turbo`，但网页只挂载研究与文件工具。修复重点是补齐实际能力，并让回复依据当前工具直接执行，不能用长篇替代建议代替产物。

## 性能定位与调整

既有 Speedtest/Cloudflare 任务总耗时约 313 秒，工具执行合计约 25 秒；其余约 288 秒包括模型响应、文本生成、调度及启动，不能全部归因于网页访问，也不能未经进一步测量就全部称为模型推理时间。

- 提示词改为：已有 URL 优先读取静态正文；需要动态内容再使用浏览器。navigate 已返回正文，无需例行重复 snapshot。
- 保留按需要查证事实的要求，减少无必要的来源遍历、整篇文件重写和重复最终报告。
- save_document 实际写入后自动读回并比较字节，返回 bytes 和 SHA-256；存储校验不代表事实正确。无需只为确认落盘再额外调用模型读取整篇文件。
- 静态读取超时从 25 秒收紧到 10 秒，失败后仍可改走浏览器；不关闭网络安全检查。
- 增加 performance.mjs 与 timing.json：总时间、工具区间并集、非工具时间、首个 CLI 输出时间及工具调用数。首个 CLI 输出不等于模型 API 的首 token。

同一条 Speedtest/Cloudflare 请求本次完成约 211.7 秒，8 次调用；之前约 313.2 秒、18 次调用。单次对照约缩短 32%，但当次网络环境不同（两次静态读取超时），不是严格受控基准，也不能承诺所有任务按此比例加速。

证据：`web/.runtime/runs/33ef68a8-bdfd-4190-aaa7-56b16c8b4ed2/timing.json` 与 `web/.runtime/performance-test-result.json`。

## 接通实际生图

- `agent/tools/image-generation/client.cjs`：沿用既有 audio-agent 的 SiliconFlow `/images/generations` 请求方式，使用共享 key、base URL 和 image model，不把密钥放进提示词或前端。
- `agent/tools/image-generation/index.cjs`：向 DSH 注册 image_generate。用户明确要求图片时直接调用，未指定的风格/尺寸采用默认值；不先搜索写提示词教程，不擅自换成 SVG。
- 下载服务返回图片走既有公开网络策略，DNS 固定 IP、逐次重定向校验；不向图片 CDN 转发 API key。
- 某次真实下载返回通用二进制 MIME，首次过严的 MIME 校验导致失败。已允许二进制响应，保存前仍校验 PNG/JPEG/WebP 文件签名和 20 MB 上限；不允许 SVG 伪装成图片输出。
- `web/server.mjs`：传递生图模型环境，收集 media 文件，返回图片类型、内联图片响应及 nosniff。
- `web/src/App.tsx` / `styles.css`：消息中直接展示实际图片，提供下载与“AI 生成”标签；过程显示“正在生成图片”。
- 回复规则改为默认简短、先交付结果；用户未询问时不展开法律/平台政策或工具限制讨论。真正失败时简短说明具体错误。

接口参考：[SiliconFlow Image Generation](https://siliconflow.readme.io/reference/imagegeneration)。模型以共享配置与真实调用验证为准，参考页部分旧模型枚举不是本工程能力清单。

## 真实生图验证

输入：`生成一张库里打篮球的图片。`

运行编号：`9ed22d3e-46df-4ed9-af92-ec0e5b7d698f`。

- 端到端 11.3 秒，一次 image_generate，工具耗时约 6.1 秒。
- 最终回复：`这张库里打篮球的图片已生成，并显示在页面上。🏀`
- 真实输出 PNG：768×1024，位于对应运行目录 media 下；已实际打开检查。
- 浏览器展示单独使用上述真实 API 回执进行前端回放测试，图片仍从真实后端读取，未额外调用生图模型。naturalWidth/naturalHeight 为 768×1024，证明实际加载并解码；这项回放不是第二次端到端生图。
- 截图：`web/.runtime/validation/image-generation-ui.png`。
- 生图客户端、网络策略、任务文件校验与计时测试共 9 项通过；TypeScript/Vite 构建通过。

本批没有接入图片编辑或视频生成，也没有更换聊天模型。模型生成图片仍可能出现文字、号码或细节偏差；不把成功下载等同于像素级准确。
