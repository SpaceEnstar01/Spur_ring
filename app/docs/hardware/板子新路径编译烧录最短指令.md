# 板子新路径编译烧录最短指令

工程根目录：

```text
/Users/spur/X/space/claudeV2/hardware/3_boardring
```

目标：在新路径下重新配置、编译、生成 Bootloader Settings，并完整烧录，使手机能扫到 `BCL603xxxx`。

---

## 1. 重新配置并编译

```bash
cd /Users/spur/X/space/claudeV2/hardware/3_boardring

rm -rf build-arm

cmake -S . -B build-arm \
  -DCMAKE_TOOLCHAIN_FILE=cmake/arm-none-eabi-gcc.cmake

cmake --build build-arm --target backup_bcl603s2p -j1
```

成功标志：

```text
[100%] Built target backup_bcl603s2p
```

产物：

```text
/Users/spur/X/space/claudeV2/hardware/3_boardring/build-arm/backup_bcl603s2p.hex
```

---

## 2. 生成 Bootloader Settings（必须）

若缺少 settings，Bootloader 可能进入 `DfuTarg`，手机扫不到 `BCL603xxxx`。

```bash
PYTHONPATH=/Users/spur/X/space/claudeV2/hardware/3_boardring/compat/nrfutil_py313 nrfutil settings generate \
  --family NRF52840 \
  --application /Users/spur/X/space/claudeV2/hardware/3_boardring/build-arm/backup_bcl603s2p.hex \
  --application-version 1 \
  --bootloader-version 1 \
  --bl-settings-version 2 \
  /Users/spur/X/space/claudeV2/hardware/3_boardring/build-arm/settings_backup_gcc_ble_adpcm_notify_8s_v1.hex
```

确认文件存在：

```bash
ls -la /Users/spur/X/space/claudeV2/hardware/3_boardring/build-arm/settings_backup_gcc_ble_adpcm_notify_8s_v1.hex
```

---

## 3. 完整烧录

```bash
cd /Users/spur/X/space/claudeV2/hardware/3_boardring
JLinkExe -device NRF52840_XXAA -if SWD -speed 1000 -autoconnect 1
```

进入 `J-Link>` 后执行：

```text
erase
loadfile /Users/spur/X/space/claudeV2/hardware/3_boardring/backup_code/bcl603s2x/bcl603s2l/dfu/s140_nrf52_7.2.0_softdevice.hex
loadfile /Users/spur/X/space/claudeV2/hardware/3_boardring/backup_code/bcl603s2x/bcl603s2/boot/nRF5_SDK_17.0.2_d674dde/examples/dfu/secure_bootloader/pca10056_s140_ble/arm5_no_packs/_build/boot.hex
loadfile /Users/spur/X/space/claudeV2/hardware/3_boardring/build-arm/backup_bcl603s2p.hex
loadfile /Users/spur/X/space/claudeV2/hardware/3_boardring/build-arm/settings_backup_gcc_ble_adpcm_notify_8s_v1.hex
r
g
q
```

烧录顺序：

| 顺序 | 文件 | 作用 |
| --- | --- | --- |
| 1 | SoftDevice | BLE 协议栈 |
| 2 | Bootloader | 启动 / DFU |
| 3 | App hex | 主业务固件 |
| 4 | Settings hex | 标记 App 有效，避免卡在 `DfuTarg` |

---

## 4. 烧录后验证

用 **nRF Connect** 扫描：

| 看到的名字 | 含义 |
| --- | --- |
| `BCL603xxxx` / `BCL603_...` | 正常，主固件在广播 |
| `DfuTarg` | 缺 settings 或 App 未被 Bootloader 认可，回到第 2、3 步重做 |
| 完全没有 | 检查供电、复位、J-Link 是否烧录成功 |

RN App 扫描匹配前缀：`BCL603` / `SmartRing` / `Recording` / `Ring`。
