## 实现

- 纯白首页保留侧栏、Logo、欢迎语与主输入框；小快捷入口下是三条单行主动推送，再下方四张横排功能卡（手机两列）。
- 主动推送是独立 `proactiveFeed.ts` 中的示例，首页与详情都说明未接入个人数据，不声称已读取真实邮件或 YouTube 账号；准备后续任务只填充输入框，用户提交后才实际执行。
- 提交需求后在同一主区域展示用户气泡、Agent 回复、可折叠的真实执行活动和底部追问框；不再自动呈现双栏大面板。
- 每轮仍使用既有独立 run ID，通过 parentId 关联同一对话；不改后端协议。追问继续传递既有上下文链，恢复历史时补取祖先结果。
- 后台任务轮询位于 App 层，切回首页不取消任务，不自动重复 POST。保留失败、连接中断、待核对、运行及完成状态，错误可查询原任务。
- 只有真实文件、图片、视频交付物才出现成果预览按钮；右侧抽屉复用 AgentWorkspace 真实文件、来源与媒体展示。原有成果库及邮箱审批组件未修改。
- 抽屉支持 Esc、遮罩关闭、Tab 焦点循环与关闭后恢复焦点；响应式布局和 reduced-motion。
