- 可选“转写后自动 AI 回复”：新版首次打开明确确认文字发送到 Java / 硅基流动后开启，也可在设置中开启或关闭。开启时只包含最新一条已有录音及此后新增录音，不批量发送其他历史内容，不附带全部笔记。回复按录音持久化，首页显示状态与摘要，详情显示完整内容；“继续对话”带上已有问答，不重复生成。失败不自动重试；后台、关闭开关或删除记录时中止当前自动请求，不能撤销服务商已接收的请求或费用。

转写与 AI 整理可能出现错字和遗漏，保存前请核对。仅在手动请求 AI 回复或明确开启自动回复后，才向 Java / 硅基流动发送文字；自动回复超过 8000 字的转写不会截断上传，会提示分段处理。Java 原有云端转写接口为兼容保留，当前 APP 已不再调用。
当前录音仅支持前台使用，不包含后台持续录音、实时转写、说话人区分或 OTA UI。

## Java 接口

AI 使用 `/api/chat/stream` SSE 接口，通过原生 XHR 增量显示文字；首字等待、分段停顿和总时限分别处理。录音 AI 生成中的内容持续保存，中断后保留已生成文字并显示重试入口；不会在失败后自动重复请求。重试为重新生成，不保证延续上次文字。正在生成和未完成的回复不能作为完整回答直接继续对话。

Release/TestFlight 默认连接 `https://spur-api.aierdream.com`，不依赖开发电脑或同一 Wi-Fi。
升级后会清除已保存的旧局域网/HTTP 地址，保留用户明确设置的其他公网 HTTPS 地址。
Debug 联调先启动相邻的 `my-app-server`；首页设置可修改地址，真机填写开发电脑局域网地址。
Android 默认仅 Debug 允许 HTTP；正式环境使用 HTTPS。

### iPhone 本地开发网络

手机里的 `127.0.0.1` 指手机自身。Java 默认仅监听电脑回环地址，真机无法访问。
仅在可信的开发局域网联调时，可临时以 `SERVER_ADDRESS=0.0.0.0 java -jar target/my-app-server-0.1.0.jar` 启动 Java；不要将无鉴权的调试服务暴露到公网。
电脑与手机须处于可互访的同一网络，并允许 Spur 的 iOS 本地网络权限。公司/访客 Wi-Fi 可能隔离客户端。

iOS Debug 构建支持 `SUPR_API_URL=http://电脑局域网IP:8080` Xcode build setting。真机使用随包打包的 JS，避免等待不可达的 Metro 导致启动超时；修改 JS 后需重新构建安装。模拟器仍使用 Metro。
地址不写死在源码，Debug 的 SuprConfig 模块读取构建设置；未配置时从 Metro host 推导，最后回退至模拟器/USB 调试的本机地址。
Release 不读取这些开发覆盖设置，仅允许保存公网 HTTPS 地址，默认使用上述正式域名。
域名目前仅健康检查已验收，AI 接口须在后端 SSE 保活镜像部署及公网流式验收后再用于 TestFlight 发布。
APP 设置页可以手动修改、保存地址和检测 Java 连接；检测成功只代表服务可访问，不代表模型额度充足。

# 录音闹钟执行（iOS 26+）

- 首页 agent 的 ACTIONS 区可独立开启「录音闹钟自动执行」，用户手动授权 AlarmKit 后生效；默认关闭，不随 AI 自动分析开关开启。
- 手机本机解析明确的中文单次指令，例如「帮我定明天早上八点的闹钟」「帮我定十分钟后的闹钟」。不依赖 Java 或大模型，不上传录音文字。当前不是通用工具调用引擎；重复、多个时间和其他未支持的句式留待确认，不猜测执行。
- 仅开启后新录音可自动执行。戒指录音需要 APP 实时观察到录制过程、随后一次同步只新增一个文件且在十分钟内完成，才能确认原始时间；离线/历史/批量同步等无法确认原始时间的情况要求填写新指令。文件修改时间不能作为自动执行的依据。
- AlarmKit 创建真实系统闹钟，锁屏可响铃，但不添加到苹果「时钟」APP 列表；低于 iOS 26 不用普通通知冒充闹钟。自动同步/转写/执行需要 APP 在前台，系统闹钟一旦创建后由 iOS 管理。
- 执行记录在调用系统前落盘；持久 UUID、串行队列、原生系统查询和原生 ledger 防止重试/重启/重复同步再次创建。系统返回成功后才显示已设置。中断需先对账，不自动重试不确定的副作用。
- 首页可确认、手动重试、刷新状态、取消；取消后保留去重记录。关闭自动执行或删除源录音不会取消已创建闹钟，须单独取消。已结束/被系统移除的闹钟不自动恢复。
- 隐私声明 `NSAlarmKitUsageDescription` 已配置，AlarmKit 使用弱链接及版本检查，不提高 APP 全局最低 iOS 版本。不需要新的服务端接口、密钥或 Java 部署。
