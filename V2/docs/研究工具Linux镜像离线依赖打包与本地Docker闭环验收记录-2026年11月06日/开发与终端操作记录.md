# 研究工具Linux镜像打包与本地Docker闭环验收

日期：2026年11月06日。本轮没有推送ACR、连接或更新ECS，也没有安装iOS。

## 失败与修正

用户构建报brotli无可用版本。PyPI release JSON确认有CPython3.12 manylinux x86_64 wheel；随后诊断构建能下载Brotli，却在yt-dlp报无版本，并有SSLEOFError/UNEXPECTED_EOF_WHILE_READING。问题指向Docker构建网络/SSL中断，不是已证明的版本不兼容。没有降级依赖或关闭TLS验证。

额外安装python3-venv触发的慢apt下载已停止。验证基础镜像可运行venv --without-pip后，改用Mac准备Linux wheelhouse，按PyPI SHA256验证；Agent-Reach从本地源码构建纯Python wheel。Docker校验SHA256SUMS并以--no-index安装。

## 可复用Mac终端命令

```bash
cd /Users/x/X/space/spur
/Users/x/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 \
  V2/agent/deploy/docker/prepare-research-wheels.py

docker buildx build --platform linux/amd64 --load \
  -t spur-agent:research-adapter-v1 \
  -f V2/agent/deploy/docker/Dockerfile V2

docker image inspect spur-agent:research-adapter-v1 \
  --format 'ID={{.Id}} PLATFORM={{.Os}}/{{.Architecture}}'

docker run --rm --platform linux/amd64 --network none --entrypoint node \
  --mount type=bind,src="$PWD/V2/agent/deploy/docker/research-smoke.cjs",dst=/tmp/research-smoke.cjs,readonly \
  spur-agent:research-adapter-v1 /tmp/research-smoke.cjs
```

Python路径为本机现有运行时，可换为带pip的Python3.12。需要先准备wheelhouse；仅Python安装步骤离线，首次完整构建仍可能下载基础镜像、Node和浏览器依赖。
