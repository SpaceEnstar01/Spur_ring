# 阿里云音频后端最短运行指令

## 0. 对外 HTTPS（已上线）

```text
https://api.hispurring.com
```

健康检查：

```bash
curl -sS https://api.hispurring.com/health
```

App 生产环境使用该地址；本机 `18987` 仅给 Nginx 反代。

## 1. 配置（阿里云 Workbench）

```bash
cd /opt/audio-agent
nano .env
```

```env
AUDIO_AGENT_PORT=18987
AUDIO_AGENT_PUBLIC_BASE_URL=https://api.hispurring.com
AUDIO_AGENT_STT_PROVIDER=volcengine
VOLCENGINE_ASR_APP_ID=你的豆包语音_APP_ID
VOLCENGINE_ASR_ACCESS_TOKEN=你的豆包语音_ACCESS_TOKEN
VOLCENGINE_ASR_RESOURCE_ID=volc.seedasr.auc
DEEPSEEK_API_KEY=你的_DEEPSEEK_API_KEY
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
```

```bash
chmod 600 .env
```

不要把 Access Token 或 API Key 写入文档、聊天或日志。

## 2. 更新部署包（代码变化时）

Mac 终端 1：

```bash
cd /Users/spur/X/space/claudeV2/apps
python3 -m http.server 19000
```

Mac 终端 2：

```bash
ngrok http 19000
```

阿里云 Workbench（替换 ngrok 地址）：

```bash
curl -L "https://xxxx.ngrok-free.app/audio-agent-cloud.tar.gz" \
  -o /root/audio-agent-cloud.tar.gz
tar -xzf /root/audio-agent-cloud.tar.gz -C /opt
cd /opt/audio-agent
bun build src/server.ts --target bun --outdir /tmp/audio-agent-build
```

部署完成后可关闭 Mac 上的 Python 和 ngrok。

## 3. 启动或重启（阿里云 Workbench）

```bash
pkill -f '^bun run src/server.ts$'
cd /opt/audio-agent
nohup bun run src/server.ts >/var/log/audio-agent.log 2>&1 &
```

## 4. 检查服务（阿里云 Workbench）

```bash
curl http://127.0.0.1:18987/health
tail -n 5 /var/log/audio-agent.log
```

成功标志：

```text
{"ok":true,"service":"audio-agent",...}
Audio Agent listening on http://localhost:18987
```
