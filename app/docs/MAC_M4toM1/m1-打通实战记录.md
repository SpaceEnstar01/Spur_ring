## 1. 总体路径（我们实际怎么走的）

```text
升系统到可装 Xcode 26.2
→ 装 Xcode 26.2（Developer Downloads .xip）+ iOS 平台/模拟器
→ 修 Homebrew（旧版不认 macOS 26）
→ 装 Node 20 + CocoaPods
→ npm install + pod install
→ 写 .xcode.env.local
→ Xcode 登录开发者账号、签名、登记真机
→ 修 Xcode 26 + CocoaPods modulemap 扫描问题
→ Release 命令行编过
→ 卸旧包 → 安装 → 启动
```

## 2. 分步实操与关键坑

### 2.1 系统过旧：必须先升 macOS

初始 M1 为 **macOS 12.6.1**，Xcode 26.2 要求 **macOS 15.6+**。  
**不能**用旧 Xcode（15/16）硬编本工程（Expo 52 / RN 0.76）。

处理：软件更新直接升到 **macOS Tahoe 26.6.1**（本机可升），再装 Xcode。

### 2.2 Xcode：用 Developer Downloads 对齐 26.2

- 直链（需登录 Apple Developer）：  
  `https://developer.apple.com/services-account/download?path=/Developer_Tools/Xcode_26.2/Xcode_26.2_Apple_silicon.xip`
- 解压后拖到 `/Applications`
- 必做：

```bash
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
sudo xcodebuild -license accept
xcodebuild -version   # 期望 Xcode 26.2 / 17C52
```

首次打开勾选 **iOS** 平台（真机必需）。模拟器 runtime 版本可以是 26.3.x，不必死磕 26.2。

真机若提示 `iOS x.x Not Installed` / `unpaired`：在目的地菜单点 **Get**，并完成「信任此电脑」+ 开发者模式。

### 2.3 Homebrew：4.4.x 在 Tahoe 上直接挂

旧 Homebrew（如 **4.4.12**）报错：

```text
unknown or unsupported macOS version: "26.6.1"
```

官方 GitHub 在国内很慢/易断。本次用 **中科大镜像** 升到 **5.1.13**：

```bash
cd /opt/homebrew
git remote set-url origin https://mirrors.ustc.edu.cn/brew.git
git fetch --tags --force origin
git checkout -f 5.1.13
brew --version   # Homebrew 5.1.13
```

> 目标：≥ 5.0.0（正式支持 Tahoe）；5.1.13 可用。

### 2.4 Node 20

指南要求 Node **20.x**。本机曾有旧 Node 18（`/usr/local` / nvm）。  
最终使用：

```bash
export PATH="/opt/homebrew/opt/node@20/bin:$PATH"
node -v   # v20.20.2
```

并写入 `~/.zshrc`。  
（brew 因 Portable Ruby 下载失败时，也曾用官方 Node 二进制落到同一路径。）

### 2.5 CocoaPods

`brew install cocoapods` 曾卡在 **Portable Ruby**（ghcr / 镜像 404）。最终装上 **1.16.2**，`pod` 在 `/opt/homebrew/bin/pod`。

工程依赖：

```bash
export PATH="/opt/homebrew/opt/node@20/bin:$PATH"
cd /path/to/spur/app/mobile
npm install
cd ios && pod install
```

必须打开 **`RecordingRing.xcworkspace`**，不是 `.xcodeproj`。

Node 路径（本机绝对路径，勿抄源机）：

```bash
echo 'export NODE_BINARY=/opt/homebrew/opt/node@20/bin/node' \
  > ios/.xcode.env.local
```

### 2.6 签名与真机

1. Xcode → Settings → Accounts：登录**有权限的付费开发者账号**
2. Target **RecordingRing** → Signing & Capabilities  
   - Automatically manage signing  
   - Team 选同事账号 Team（本次 `YPPBAGJ2Q5`）  
   - Bundle ID：`com.spur.recordingring`
3. 若提示设备未登记：点 **Register Device**
4. 若安装报 **application-identifier 不匹配**（旧包另一 Team 签的）：

```bash
xcrun devicectl device uninstall app --device <DEVICE_ID> com.spur.recordingring
# 再 install
```

## 3. 最大编译坑：Xcode 26 Explicit Modules + CocoaPods modulemap

### 现象

编真机时大量红错，核心类似：

```text
module map file '.../Build/Products/Release-iphoneos/EXAV/EXAV.modulemap' not found
```

随后连锁：`Unable to find module dependency: 'Foundation' / 'UIKit' / 'ExpoModulesCore'...`  
**Pods 其实已装好**，`Pods/Target Support Files/EXAV/EXAV.modulemap` 存在；是扫描过早。

### 原因

Xcode 26 默认 **Explicitly Built Modules**；CocoaPods 把 `-fmodule-map-file` 指到 **Build/Products** 下尚未生成的 modulemap，主工程 `ExpoModulesProvider.swift` 先扫就炸。

### 修复（已写入工程）

1. **关掉 Explicit Modules**（主工程 + Pods，`Podfile` `post_install`）  
2. **改写聚合 xcconfig**：把 App 用的 `-fmodule-map-file="${PODS_CONFIGURATION_BUILD_DIR}/..."`  
   改成指向已有的  
   `"${PODS_ROOT}/Target Support Files/<Pod>/...modulemap"`  
   （只改 `Pods-RecordingRing.*.xcconfig`，不动各 Pod 自己的 xcconfig）

改完后重新 `pod install`，再编。

相关文件：

- `app/mobile/ios/Podfile`（`post_install`）
- `app/mobile/ios/RecordingRing.xcodeproj/project.pbxproj`（`SWIFT_ENABLE_EXPLICIT_MODULES` / `CLANG_ENABLE_EXPLICIT_MODULES = NO`）

### 成功编译与安装命令（对齐本次）

```bash
export PATH="/opt/homebrew/opt/node@20/bin:$PATH"
cd /path/to/spur/app/mobile/ios

# 可选：清缓存
rm -rf ~/Library/Developer/Xcode/DerivedData/RecordingRing-*

xcodebuild \
  -workspace RecordingRing.xcworkspace \
  -scheme RecordingRing \
  -configuration Release \
  -destination 'generic/platform=iOS' \
  -allowProvisioningUpdates \
  DEVELOPMENT_TEAM=YPPBAGJ2Q5 \
  SWIFT_ENABLE_EXPLICIT_MODULES=NO \
  CLANG_ENABLE_EXPLICIT_MODULES=NO \
  COMPILER_INDEX_STORE_ENABLE=NO \
  -jobs 2 \
  build

APP=$(ls -d ~/Library/Developer/Xcode/DerivedData/RecordingRing-*/Build/Products/Release-iphoneos/RecordingRing.app | head -1)
# DEVICE 用：xcrun devicectl list devices
xcrun devicectl device install app --device <DEVICE_UUID> "$APP"
xcrun devicectl device process launch --device <DEVICE_UUID> com.spur.recordingring
```

M1 8GB 上全量 Release 大约 **数十分钟**；编的时候少开其它 App。

## 5. 给下一位的最短建议

1. **先升系统再装 Xcode 26.2**，不要降级 Xcode 硬编。  
2. Homebrew 务必新到认 Tahoe；国内优先镜像。  
3. **强制 Node 20**，写好 `ios/.xcode.env.local`。  
4. 只开 **`.xcworkspace`**。  
5. 若出现 `EXAV.modulemap not found` 海量假错：确认 `Podfile` 里 Explicit Modules 关闭 + 聚合 xcconfig 重写已生效，再 `pod install` 后编 Release。  
6. 换 Team 重装：先卸手机上的旧 `com.spur.recordingring`。
