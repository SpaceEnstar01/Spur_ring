# 研究工具 Adapter 接入 DSH 与本地真实验证

日期：2026年11月06日。本轮授权两步：统一Adapter和能力清单；接入DSH并验证本地调用。不进行Docker打包、ECS部署、iOS安装或网页UI开发。

## 工程改动

- V2/agent/tools/research-adapter/capabilities.cjs：平台、动作与启用清单，区分首选提供方和真正可执行路径。
- adapter.cjs：参数校验、固定CLI、任务独立HOME、凭据隔离、并发/次数/输出限制、来源域名检查、统一结果、缓存与平台停止状态。
- index.cjs：注册research_capabilities、research_search，保存证据和事件日志。
- mediacrawler.cjs：明确禁用接口，不包含启动第三方进程的路径。授权和运行验证未完成，不能通过环境变量直接解锁。
- adapter.test.cjs：7项针对性测试。
- README.md：配置、行为和范围说明。
- V2/web/server.mjs：默认关闭的SPUR_RESEARCH_ADAPTER_ENABLED=1注册入口；传递管理员配置的SPUR_AGENT_REACH_BIN和SPUR_RESEARCH_PROVIDER_PROXY。修正启用时公开搜索不应被要求OAuth，保留自有频道Analytics与其他既有工具。

## 真实验证

- Adapter单元测试7/7通过：非法输入与CLI参数、未验证平台禁用、凭据隔离和缓存、平台挑战停止、异常输出及来源域名、并发限制、小红书公开回退。
- 既有鉴权、App连接及邮件回归31/31通过。
- 服务端与插件语法检查通过。
- 实际Adapter调用：YouTube3条，10.346秒；小红书3条，2.614秒；抖音ACTION_UNAVAILABLE，未启动MediaCrawler。
- 实际DSH Headless挂载新插件：调用research_search取得一条YouTube结果（5.510秒），随后调用现有save_document保存806字节报告。整个DSH运行24.56秒，exitCode=0、timedOut=false。事件与证据见evidence目录。
- DSH原始报告有一句“仅YouTube搜索可用”，此说法过宽：清单还启用了小红书public-web搜索。原始输出保留不改，不能用这句模型概述替代能力清单；本轮YouTube任务没有调用小红书。

本地验收只使用现有模型凭据，CLI不接收模型、邮件、Notion或OAuth凭据；没有登录、导入浏览器会话或对外写入。测试运行目录/private/tmp/spur-research-adapter-validation-20261106；Agent-Reach来自此前隔离虚拟环境。

## 限制与下一阶段

开关默认关闭，现有生产Docker没有Adapter和Python依赖，不能直接开启。未做生产多用户隔离、全局任务队列或跨工具的统一限流阻断；本轮限制为每任务Adapter实例，现有工具仍由DSH既有权限与提示词管理。

下一阶段需先审查打包范围与固定依赖，再做本地linux/amd64容器测试。只将允许的Agent-Reach能力纳入候选镜像；MediaCrawler不因接口存在而获得生产授权。随后另行提交ECS更新与iOS验收计划，等待用户确认。
