# 录音戒指 APP 四大页面设计

录音戒指 APP 由四个核心页面组成：

```text
健康｜AI 洞察｜录音｜小龙虾
```

四个页面分别负责健康数据、录音内容理解、原始录音管理和语音任务执行，功能边界清晰，能够覆盖戒指的主要使用场景。

## 1. 健康

核心链路：

```text
戒指数据 -> 健康趋势 -> 异常提醒
```

主要功能：

- 睡眠数据
- 心率监测
- 血氧监测
- 活动量统计
- 日、周、月健康趋势
- 健康报告
- 异常数据提醒
- 戒指电量与佩戴状态

## 2. AI 洞察

原“大模型”页面建议命名为“AI 洞察”。

核心链路：

```text
全部录音 -> 跨录音分析 -> 总结与洞察
```

主要功能：

- 今日录音总结
- 每周录音总结
- 多段录音合并总结
- 想法自动聚类
- 高频人物与话题
- 待办事项提取
- 搜索历史录音
- 向 AI 询问历史录音内容

## 3. 录音

核心链路：

```text
原始录音 -> 转写文本 -> 文件管理
```

主要功能：

- 按时间线展示录音
- 播放原始录音
- 查看转写文本
- 重新转写
- 重命名录音
- 添加标签
- 搜索和筛选
- 单条录音总结
- 上传本地音频文件

## 4. 小龙虾

小龙虾页面负责接收并展示用户通过戒指发出的语音操作指令。

核心链路：

```text
语音指令 -> Agent 执行 -> 结果返回
```

主要功能：

- 展示正在执行的任务
- 展示已完成任务
- 展示待确认草稿
- 查看 Agent 输出
- 查看报告网页链接
- 查看邮件或 App 返回状态
- 重新执行任务
- 补充新的语音指令

## 5. 四个页面的功能边界

```text
健康：管理身体数据
AI 洞察：理解全部录音内容
录音：管理原始录音与转写
小龙虾：执行用户语音命令
```

其中：

- “录音”关注原始内容的保存、播放、转写和管理。
- “AI 洞察”关注多条录音的综合理解、总结和知识提取。
- “小龙虾”关注用户明确下达的任务及其执行结果。
- “健康”关注戒指采集的身体指标和健康趋势。

## 6. 底部导航

建议采用四栏底部导航：

```text
健康｜AI 洞察｜录音｜小龙虾
```

用户使用路径可以概括为：

```text
健康看身体
AI 洞察看总结
录音看原始内容
小龙虾看任务结果
```
