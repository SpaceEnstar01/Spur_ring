# 接通网页文字生成视频与异步任务恢复

日期：2026-11-01。只修改 V2，未修改原工程、上游 Harness、邮箱模块或线上部署。

## 完成内容

网页 DSH 新增 `video_generate` 与 `video_status`，复用共享 SiliconFlow API key、base URL 和 `SPUR_VIDEO_T2V_MODEL`。首轮接通文字生成视频，模型为 `Wan-AI/Wan2.2-T2V-A14B`；没有声称图生视频、参考图上传或任意自定义时长已经实现。

执行链：用户提出视频需求 → DSH 提交一次生成 → API 返回 requestId → 本地持久化任务 → 网页立即显示任务卡片 → 后台查询原任务 → 下载完成结果 → 网页显示播放器和下载入口。

已提交的请求不会因为模型继续回复、网页刷新或服务重启而重新提交。用户追问进度时使用 video_status，不重新调用生成。

## 主要代码

- `agent/tools/video-generation/client.cjs`：调用 `/video/submit` 与 `/video/status`，支持 1280×720、720×1280、960×960；不发送未经核实的 duration/帧数字段。
- `index.cjs`：挂载 DSH 工具；同一轮任务只允许一份提交记录，重复工具调用返回已存在任务。网络中断导致提交结果不明时保留 submission_unknown，不自动重提；明确失败不伪称成功。
- `jobs.cjs`：原子写入 JSON、后台查询、下载重试与启动恢复。单进程最多三个视频任务并行查询，正常约每 10 秒查询上游；短暂网络失败退避重试，反复失败暂停，可恢复查询原 requestId。超过 24 小时暂停，不默认取消上游任务。
- `web/server.mjs`：挂载工具、传递模型配置、启动视频后台查询，新增任务列表、状态、文件与恢复查询接口。
- `web/src/VideoTask.tsx`：排队/生成/下载/完成/失败状态，完成时显示视频；刷新或新开聊天后可查看最近任务。等待期间不占着聊天请求。
- `web/video-stream.mjs`：MP4 分段响应，支持 GET/HEAD、Range 206、后缀范围与无效范围 416，支持播放器加载及拖动。
- `agent/tools/playwright-browser/public-network.cjs`：二进制下载新增 MP4 类型，仍使用公开 IP 校验、DNS 固定连接和逐次重定向检查；不向 CDN 转发 API key。文件上限 200 MB，保存前检查 MP4 签名。

任务与视频保存在 `web/.runtime/video-jobs/`。密钥不存入任务 JSON 或前端。当前是本机单用户、单服务进程实现；不是已完成的多租户、分布式任务系统。
