# Agent 十种真实卡片展示

用户确认：录音记录保持简洁，Agent 对不同意图和交付使用至少十种可区分的卡片，清理界面反复出现的 Demo 标签。范围仅 V2，不修改原工程、录音/转写/SDK，不接入新外部执行服务。

## 展示与意图分离

`src/intent/presentation.ts` 定义十种视觉类型，`src/components/IntentUpdateCard.tsx` 负责展示。`src/components/IntentArtwork.tsx` 是本地 SVG 内容插画，不使用无关旅行照片代表真实任务，也不加载外部图片。

| 展示 | 主要构成 |
| --- | --- |
| idea | 引用式灵感卡、淡紫背景；不变为提醒 |
| decision | 方向横幅、确认标记、当前/旧方向区分 |
| commitment | 人物头像、交付方向、交付物与截止双栏 |
| reminder | 日期方块、时间、确认状态、页内提醒说明 |
| analytics | 指标块及实际基线对比条；无数据展示范围与分析入口 |
| report | 文档插画、报告目录、章节预览 |
| script | 片板插画、三格分镜和结构预览 |
| email | 信件预览、收件人、主题、正文摘要及未发送状态 |
| partnership | 合作对象、合作摘要、交付范围和下一步 |
| clarification | 编号问题、纠错/进度目标确认入口 |

kind/frame 仍使用原语义与八框架，presentation 是独立的视觉提示。不能通过选择某种外观创建承诺、授权或外部动作。旧台账没有 presentation 时按已有语义与主题自动选择；任务只缺个别信息时仍保留邮件/合作等任务样式，而非全变成同一种问题卡。

`src/intent/legacyPresentation.ts` 将旧 AI 回复适配为成果卡，原回答、文件、分类和状态不修改，不重新上传。旧脚本需正文确有足够脚本内容，不能仅因原文说“提醒我写脚本”就冒充已交付脚本。

首页不再追加未分析录音的普通列表，旧记录仍可从折叠的 Review captures 入口逐条整理，Projects / 录音记录保留原查看与删除确认。Memory 使用全部完成回答，避免已分类卡片的旧回答被过滤。

## 数据展示约束

模型可选返回 metrics：label/value/baseline/unit/sourceSpan。每个数值、单位及原文引用必须对应本次实际输入；不使用参考数字、不依据模型自己的报告正文反推数据。缺少证据的指标直接不显示。基线条只在同一指标的当前值和基线值均有效时绘制；不伪造趋势序列或百分比。详情展示指标来源原句。

## 单一 Agent 内容流与自然尺寸

按用户确认移除首页 Today / Projects / Memory 导航及 Creative library 分区。录音记录和笔记仍从侧栏访问，底层数据不删除。结构化意图和已有分析进入同一内容流；需要处理的意图优先，首个真实结果保留靠前，其余位置稳定穿插参考分析、脚本、邮件和商业合作卡片，每个参考卡后插入最多两条真实结果。超出插槽数量的真实结果全部保留，刷新不随机洗牌。没有真实结果时展示原参考卡片；参考内容的详情来源说明保留，不构造虚假真实履历。

十种分类不约束尺寸。短想法、单条提醒和单个澄清问题采用紧凑布局，最大宽度分别为容器的 86% 或 94%；承诺卡为 94%，报告、脚本及分析保留完整宽度。提醒仍需要明确确认时间，紧凑卡点击进入原有详情及操作。无更改意图权限、提醒执行或邮件发送逻辑。

## 按阶段选择交互，而非全部展示为卡片

本轮用户确认采用混合交互。新增 `src/intent/interaction.ts`，依据现有意图和状态选择：轻记录、暂停等待、进度行、变更审阅、澄清问答、决定/时间确认、清单预览、完整成果。完整报告、脚本、邮件、数据分析仍沿用已有详情和卡片。终态不会因遗留问题重新变成提问，暂停状态不继续催办。

新增 `AgentConversation` 用自然段落、细标记和可换行选项呈现。实际事项的 Answer this 与明确受众/地点/语气选项进入该事项详情，填入 follow-up；仍通过既有 Prepare Updated Version 审阅/确认流程请求云端，之后手动采用版本。决定的肯定选项也是审阅下一步，不声称已执行；提醒进入原时间确认流程。Not now / Later 使用已有 ledger transition 保存 paused，保留版本校验和历史；原录音、笔记保持原样。展示层不会创建授权或发送邮件。

新增八种独立本地交互情境，穿插于参考成果之间：A/B 方案、日程冲突、交付变更、数据缺口、可勾选准备清单、开场句选择、阶段回顾、等待报价。点选后显示对应下一步，支持改选；样例状态仅保存在组件本地，不污染真实任务、日历、收件箱。About this scenario 可展开来源说明。当前日程冲突和合作回复仅为参考情境；尚未新增外部平台连接或后台自主监控。
