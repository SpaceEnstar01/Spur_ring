# 录音戒指 SDK 迁移说明

来源：`spur_team/app/mobile`，迁移日期：2026-10-17。

## 已迁移

- Android：7 个厂商 AAR/JAR、YanqiangVoiceModule 与 ReactPackage 注册。
- iOS：RingSDK / AB_FOTA XCFramework、原生事件桥、录音 Opus 转 M4A 辅助代码。
- 扫描、停止扫描、连接、鉴权回调、断开、手动重连和启动时重连上次设备。
- 录音同步、进度回调、文件持久化列表。
- Android 转换为 OGG；iOS 转换为 M4A。

真实连接状态由厂商事件驱动，`connect()` 命令返回不代表鉴权完成。
Android 初始化保留原项目厂商 appId 与名称；这是既有 SDK 初始化参数，不是新 APP 的包名。
如厂商重新发放授权，应一起替换这些参数。

## 平台限制和待验收

- iOS 模拟器可验证页面、手机录音模块与 Java 对话/转写接口；其戒指 SDK slice 为 stub，扫描会明确返回不支持。
- 真机录音戒指未连接到当前开发环境，扫描、配对、鉴权、录音下载需要手机验收。
- 手机录音使用独立 PhoneAudio 原生模块，Android MediaRecorder / iOS AVAudioRecorder，不依赖厂商 SDK；两端输出单声道 AAC/M4A。
- 同步录音点击后可手动转写；真实戒指 OGG/M4A 文件的录制、同步、播放及识别质量仍需真机验收。OTA UI 尚未接入。
- 厂商已下载文件保留在 APP 私有目录，不会自动上传到云端。
- 硅基流动仅通过 Java 服务访问，旧项目客户端密钥头文件未迁移。

## 验收

1. 开启手机蓝牙、激活戒指，点击首页右上角进入设备页。
2. 添加戒指、授权、扫描，列表应显示真实设备。
3. 选择设备，等待鉴权完成；关闭蓝牙时首页连接状态应变化。
4. 戒指录一段音频并停止，点击同步，确认进度及首页录音卡片。
5. 重启 APP，确认上次设备重连和录音列表保留。
6. 启动 Java 服务后在 APP 对话页发送文本，验证真实回复及断网错误恢复。
7. 首页点击麦克风，授权后录制清晰语音，结束保存，确认录音卡片及本地播放；拒绝授权时不应显示录音成功。
8. 点击“转写为文字”，确认上传，核对识别结果、取消/重试、保存及“交给 AI 整理”。重复转写保存不应生成多张重复卡片。
9. 录音中切换后台或发生电话中断，确认录音结束并可保存；单次超过 10 分钟应自动结束。正式上线前进行实体手机中断与权限回归。

## 2026-10-19 本机验证

- Android ARM64 Debug APK、iOS 模拟器和 iOS 设备无签名构建均通过。
- iOS 模拟器实际启动麦克风录音、计时、停止保存 M4A 并跳转录音笔记页已验证；16 kHz 单声道 AAC 使用 32 kbps，避免模拟器 64 kbps 编码初始化失败。
- 合成中文测试音频经实际 RN multipart 客户端 → Java → 硅基流动返回识别文字；Java 直接上传 M4A / Opus OGG 均验证成功。没有将麦克风环境录音上传至服务商。
- RN 9 项测试、Java 8 项测试通过。实体手机及真实戒指仍待上述验收，不以模拟器通过代替硬件测试。
