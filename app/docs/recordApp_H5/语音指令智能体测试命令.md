# 语音指令智能体测试命令

## 1. 启动 ngrok

新开终端执行：

```bash
ngrok http 18987
```

复制输出里的公网地址，例如：

```text
https://40d6-240e-390-aa3-5a90-c07e-a6f3-f9d8-9c8.ngrok-free.app
```

## 2. 启动 audio-agent

新开终端执行，注意把 `AUDIO_AGENT_PUBLIC_BASE_URL` 换成第 1 步的 ngrok 地址：

```bash
cd /Users/spur/X/space/claudeV2/apps/audio-agent

AUDIO_AGENT_PORT=18987 \
AUDIO_AGENT_STT_PROVIDER=volcengine \
AUDIO_AGENT_PUBLIC_BASE_URL="https://40d6-240e-390-aa3-5a90-c07e-a6f3-f9d8-9c8.ngrok-free.app" \
/Users/spur/.bun/bin/bun run dev
```

看到下面内容说明启动成功：

```text
Audio Agent listening on http://localhost:18987
```

## 3. 测试语音指令智能体

本机后端测试执行：

```bash
curl --http1.1 -sS -X POST http://localhost:18987/api/agent-command-local \
  -H "Content-Type: application/json" \
  -d '{"filePath":"/Users/spur/X/space/claudeV2/apps/recording2/02ok.wav"}' \
| /usr/bin/python3 -c 'import sys,json; print(json.dumps(json.load(sys.stdin), ensure_ascii=False, indent=2))'
```

前端同事跨电脑测试执行，把地址换成当前 ngrok 地址：

```bash
curl --http1.1 -sS -X POST "https://cf09-240e-390-aa3-5a90-c07e-a6f3-f9d8-9c8.ngrok-free.app/api/agent-command-local" \
  -H "Content-Type: application/json" \
  -d '{"filePath":"/Users/spur/X/space/claudeV2/apps/recording2/02ok.wav"}' \
| /usr/bin/python3 -c 'import sys,json; print(json.dumps(json.load(sys.stdin), ensure_ascii=False, indent=2))'
```

注意：这里的 `filePath` 是后端电脑上的音频路径，不是前端同事电脑上的路径。

重点查看返回：

```json
{
  "commandText": "语音指令转写文本",
  "agentResult": {
    "content": "智能体执行结果"
  }
}
```
