## 一、授权边界

访客复用手机已经使用的 `AppConnections`，不新建第二套 OAuth，也不使用本机单用户文件 `youtube-oauth.mjs`。

- 手机回调继续是 `https://api.hispurring.com/api/connections/callback/youtube`。
- 访客回调固定为 `https://ai.hispurring.com/api/connections/callback/youtube`。网关忽略环境变量里的 `SPUR_PUBLIC_URL`，避免把个人 API 域名写进访客授权地址。
- 范围仍是 `youtube.readonly` 与 `yt-analytics.readonly`。本轮没有新增范围，所以已连接的 LEO 不需要为评论工具重新授权。
- 队列文件 `queue.json` 只保存任务文字。短期访问令牌只出现在网关发给执行环境的请求头 `X-Spur-Task-Youtube-Token`，不进入网页、队列和模型提示词。
- 执行环境的子进程环境会清空 `YOUTUBE_CLIENT_ID` 与 `YOUTUBE_CLIENT_SECRET`。

Google Cloud 现有客户端最终保留三条重定向，没有新建客户端：

1. `http://127.0.0.1:4173/api/youtube/oauth/callback`
2. `https://api.hispurring.com/api/connections/callback/youtube`
3. `https://ai.hispurring.com/api/connections/callback/youtube`

Google 页面写明设置可能需要 5 分钟到几小时生效。本次保存后，用户很快完成了网页授权。
