## 第 3 页 · PROBLEM

**AI 不缺执行能力，缺少贴近真实思考的个人入口**

### 现实发生

想法先被整理  
表达再被编辑  
信息已经损耗

打字或正式讲话都要求先组织语言；碎片、联想和犹豫往往在表达前就被删掉。

1. **表达断点**  
   用户必须把原始思考加工成完整句子，信息在入口前已经流失。

2. **上下文断点**  
   通用 AI 不知道用户长期目标、偏好、历史决策和授权边界。

3. **行动断点**  
   系统能做事，但用户仍需回到屏幕重复输入、选择工具和确认。

4. **执行** — 调用工具；跨设备完成  
5. **学习** — 结果回执；吸收纠错  

核心变化：从“把话记下来”升级为“越来越懂你的个人行动系统”。

## 第 8 页 · WHISPER CODING

**当语音成为主流输入，私密性会成为新的交互门槛**

旁人听不清，戒指听得懂。

把手靠近嘴边，小声说出代码、消息、搜索或 Agent 指令；无需拿出手机，也不必向整个空间广播。

目标体验 · 需声学验证

1. **开放办公室** — 不打扰同事，不暴露工作内容  
2. **飞机 / 高铁** — 座位上完成私密输入与任务下发  
3. **共享空间** — 咖啡店、家中、会议间隙随时说  

关键技术：近场拾音 · 结构声学 · 耳语 ASR · 环境噪声抑制

## 第 9 页 · LOSSLESS THOUGHT

**先表达完整，再交给 AI，本身就是一次有损压缩**

“不过脑子”不是不思考，而是不要求用户先把原始思考编辑成完整句子。

### 传统输入

- 原始思考：碎片 · 跳跃 · 联想 · 犹豫  
- 脑内整理：先删减，再组织语言  
- 打字 / 正常讲话：只剩可表达的部分  
- 通用 AI：得到的是加工后文本  

### Spur 输入

- 原始思考：关键词 · 停顿 · 半成品判断  
- 戒指直接捕捉：低摩擦，不过度自我编辑  
- Harness 还原：结合长期记忆，补全真实意图  
- 个人 AI：更接近用户本人的思路  

产品假设：更原始的输入 + 更长期的上下文 = 更少的思考—表达损耗
