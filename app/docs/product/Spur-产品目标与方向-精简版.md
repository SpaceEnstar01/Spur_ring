# Spur 产品目标与方向

Spur 的目标是成为一个可以随口交代事情、持续执行并主动反馈的个人 AI 助理。用户通过戒指语音或 App 对话表达需求，助理调用手机应用、网络服务和电脑能力，完成购物、订车、机票查询与订单准备，以及 PPT、报告生成等任务。

核心交互是“戒指发起，悬浮窗与通知反馈，App 承载完整对话”。用户使用其他应用时，也能收到任务进展、结果和待确认事项，通过轻量输入补充条件、选择方案或确认下一步，无需一直停留在 Spur。Android 重点采用授权后的悬浮窗与可操作通知；iOS 使用通知、锁屏实时活动及支持设备的灵动岛。

App 主页面以对话框为中心，统一呈现用户指令、任务进度、方案卡片、待付款订单和文件成果。用户说“帮我订机票”，助理搜集信息、筛选方案，并在能力支持时准备真实订单，等待用户确认或付款；状态必须准确区分查询结果、已创建订单与预订成功。

生成的 PPT、报告可以预览、下载和继续修改。用户既能在对话中提出调整要求，也能使用编辑工具修改文件，再交回助理继续处理，并保留版本。

产品方向是让对话贯穿任务全过程，让反馈跟随用户所在场景。首期重点打通已有执行能力、跨页面反馈、二次输入确认和成果修改，形成从交代需求到交付结果的完整闭环。

## 当前重点：Agent Flow 与想法沉淀

**面向自媒体变现博主，通过 Agent Flow 将即时想法转成创作操作，沉淀每天的选题、素材与脚本。** 上文描述整体产品愿景；现阶段优先完成内容创作闭环，购物、订车、订票等能力作为后续扩展方向。

**用户直接通过对话框交互，后台持续沉淀全部提交的想法。** 用户可以随口记录，也可以要求整理、生成和修改；不需要先填写表单、建立选题或进入独立的 Agent Flow 页面。戒指输入进入同一对话上下文，助理在对话里反馈记录结果、操作进展和脚本成果。Agent Flow 在后台组织创作流程，Harness 负责可靠记录与恢复。

核心点：

- **戒指随时捕捉想法。** 灵感、观点和素材通过戒指语音或对话输入进入系统，即使暂时没有执行要求，也要保存。
- **想法转成创作操作。** 按用户意图整理素材、提炼选题、生成脚本或修改已有内容；单纯记录不默认触发扩写或对外发布。
- **每日脚本持续沉淀。** 全部已提交的想法都在后台积累，不只保留最终采用的内容；按日期与选题关联，可通过对话检索、回顾和复用。
- **对话统一呈现与修改。** 用户说“整理今天的想法”“把这条写成脚本”“修改开头”，助理利用已保存记录完成处理，并在原对话交付成果、承接后续修改。
- **悬浮窗与通知承接反馈。** 用户离开 App 后仍能接收进展，补充输入和处理确认；交互同步回完整对话。
- **后台 Harness 可靠保存。** 每条想法保存原始文字或语音转写、记录时间、接收时间和来源，并关联后续任务、操作与脚本版本，形成可追溯时间线。修改保留历史，断网补传、重试去重，保存失败明确反馈。记录对象是用户提交的想法及实际操作事件。

当前核心闭环：**即时想法 → 后台完整保存 → Agent Flow 推进创作 → 对话交付与修改 → 每日内容资产沉淀。**
