# 最短执行指令

每次启动 `audio-agent` 需要开两个终端。

## 终端 1：启动 ngrok

```bash
ngrok http 18987
```

复制 ngrok 显示的公网地址，例如：

```text
https://xxxx.ngrok-free.app
```

保持这个终端不要关闭。

## 终端 2：启动 audio-agent

把下面的 `AUDIO_AGENT_PUBLIC_BASE_URL` 换成 ngrok 显示的公网地址；邮件相关变量从本地 `.env` 读取，**不要把真实密码写进文档或提交到 Git**。

```bash
cd app/cloud/audio-agent

AUDIO_AGENT_PORT=18987 \
AUDIO_AGENT_STT_PROVIDER=volcengine \
AUDIO_AGENT_PUBLIC_BASE_URL="https://xxxx.ngrok-free.app" \
AUDIO_AGENT_EMAIL_ENABLED=1 \
AUDIO_AGENT_EMAIL_TO="YOUR_EMAIL_TO" \
AUDIO_AGENT_EMAIL_FROM="YOUR_EMAIL_FROM" \
SMTP_HOST="smtp.example.com" \
SMTP_PORT=465 \
SMTP_USER="YOUR_SMTP_USER" \
SMTP_PASS="YOUR_SMTP_PASS" \
bun run dev
```

或先 `cp .env.example .env` 填好密钥后，直接按该目录 README 启动。

## 打开网页

```text
http://localhost:18987
```
