# Spur Web V5 暖白首页、十二功能入口、七色动态小球与 Agent 推送区域改造记录

日期：2026年11月07日（北京时间）。参考 Downloads 下的 `Spur_Web_V5_Seven_Colors.html` 与 `Spur_Web_V5_Codex_Complete_Prompt.md`；在既有 React/Vite 项目上增量修改。

## 实现范围

首页采用 #fafaf9，侧栏 #f6f6f5；标题 Hi, I'm Spur.，英文 Slogan 原文保留。删除旧中文副标题、旧快捷按钮、Explore with Spur 与首页中央示例推送。

三组各四项入口，准确对应内容洞察、内容创作、商业与 Agent。沿用既有预填方式，用户确认后提交真实任务。已有草稿不会被功能入口覆盖，会给出提示。没有增加模拟执行计时器。

新增七色小球：默认蓝色，红橙黄绿青蓝紫；渐变、柔和光晕、眼睛眨眼和上下浮动；桌面 pointermove 通过 requestAnimationFrame 合并，跟随限幅，移动端不跟随。颜色用 localStorage `spur-mascot-color` 保存，对非法值和存储失败回退；色点有 aria-pressed、名称、键盘原生按钮操作与可见焦点。reduced-motion 下禁用动画、过渡与鼠标跟随。品牌小点跟随相同配色。

左侧新增 Agent，保留首页、Workspace、Library、New task、历史与邮箱入口。Agent 当前使用诚实空状态：网页没有可靠个人主动推送数据绑定，不复用 V3 演示数据冒充来信或账号分析。没有真实推送行可验证，未来需接入真实身份和推送接口。

四个平台连接入口显示“尚未接入此网页授权”，点击使用既有详情抽屉解释授权和公开检索的区别。没有声称 iPhone 的授权状态已在网页同步，也没有假 OAuth。

任务协议、异步202、轮询、上下文 parentId、历史恢复、真实事件、Markdown、附件与文件URL、媒体和邮箱批准发送保持原链路，没有修改后端、DSH、Docker或ECS。每轮后端run ID仍独立，通过parentId关联同一对话；没有把每轮当作不相关的新对话。

- `V2/web/src/App.tsx`：V5 首页分组、Agent区域、平台说明和草稿保护。

无新增依赖，未修改旧任务、对话、邮箱或成果组件的数据协议。

## 使用

在 `V2/web` 执行 `npm run dev`，后端按现有配置 `npm start`，打开 http://127.0.0.1:5174/ 。端口已占用时直接使用现有服务。构建 `npm run build`，测试 `node --test tests/task-api.test.mjs`。
