# Spur Flow 产品文档

> 状态：完善中  
> 日期：2026-09-20  
> 定位：纯软件语音输入；对标 Wispr Flow；与 Spur Ring 共用同一个 Spur App 入口

---

## 1. 一句话

**Spur Flow：对着屏幕说话，尽快变成可直接使用的文字。**

只做转写 + 润色，速度做到极致。不做其他功能。

---

## 2. 产品线关系

| 产品 | 形态 | 用户 | 核心 |
|------|------|------|------|
| **Spur Ring** | 硬件 + 现有完整 App | 有戒指 | 随身按键采集 → 纪要 / Agent / 出件等 |
| **Spur Flow** | 纯软件；极简页 + 系统级输入 | 没有戒指也能用 | 仅「说话 → 可用文字」 |

同一安装包：**Spur App**。打开后先选走哪条线，两条线产品表面互不掺功能。

---

## 3. 具体表现形式（入口与形态）

### 3.1 打开 Spur App：主页面二选一

```text
打开 Spur App
        │
        ▼
   ┌─────────────┐
   │  主页面入口   │
   │             │
   │  [有戒指]    │──► 进入录音戒指硬件 App（即现在的完整 App）
   │             │     Recordings / Agent Flow / Device / 同步…
   │  [没有戒指]  │──► 进入 Spur Flow
   │  使用 Spur   │
   │  Flow       │
   └─────────────┘
```

- **有戒指**：进入当前已有的录音戒指 App 体验，功能范围不变。  
- **没有戒指 / 选 Spur Flow**：进入 **极简的 Spur Flow 页**，再一键拉起 Flow 本体。

### 3.2 Spur Flow 页：极简，只干一件事

Flow 页不是第二个全功能 App。页面上几乎只有：

- 说明：说话 → 转写 / 润色 → 可用文字  
- 主按钮：**打开 Spur Flow**（或等价文案）  
- 必要权限引导（麦克风、悬浮窗等）

不展示录音列表、纪要、Agent、戒指连接。

### 3.3 点「打开 Spur Flow」之后：真正的产品形态

目标体验对齐 Wispr Flow：**随时在别的 App 里说话出字**。

| 平台 | 形态（产品定义） |
|------|------------------|
| **Android（本版主路径）** | 点击后进入 **悬浮窗**（系统级覆盖层）。用户切到微信、邮件、笔记等任意应用时，悬浮窗仍可用：按住说话 → 出字 → 填入 / 粘贴当前输入框。 |
| **iOS** | 受系统能力限制，形态另定（如 App 内听写 + 复制，或键盘扩展等）；本版文档以 Android 悬浮窗为对齐 Wispr 的标杆描述。 |

成功画面（Android）：

```text
用户在微信 / 备忘录 / 浏览器…
        │
        ▼
  Spur Flow 悬浮窗浮在上层
        │
  按住说话 → 流式出字 → 润色
        │
        ▼
  文字进入当前输入框（或一键粘贴）
```

---

## 4. 用户是谁

- 没有 Spur 戒指，但需要日常打字场景的语音输入  
- 写消息、邮件、笔记、文档时，想少打键盘  
- 在意：开口到出字的速度，以及文字是否可直接用  

不是：会议录音用户、要出 PDF/PPT 的用户、要硬件触发的用户。

---

## 5. 核心体验（唯一主路径）

```text
打开 Spur App → 选 Spur Flow → 打开 Flow（Android：悬浮窗）
    → 按住 / 点一下开始说
    → 实时（或近实时）出字
    → 自动润色成通顺、可直接用的文本
    → 填入当前输入框 / 一键复制
```

成功标准：

1. **快**：开口到可用文字，体感接近或优于 Wispr Flow  
2. **准**：转写错误少；润色后可直接发、直接贴  
3. **简**：主页面二选一 → Flow 极简页 → 悬浮窗；无功能菜单负担  

---

## 6. 做什么（In Scope）

| 能力 | 说明 |
|------|------|
| App 主入口分流 | 有戒指 → Ring App；无戒指 → Spur Flow |
| Flow 极简页 | 仅「打开 Spur Flow」与权限说明 |
| Android 悬浮窗 | 跨应用常驻，任意输入场景说话出字 |
| 语音采集 | 手机麦克风；不依赖戒指 / 蓝牙 |
| 流式转写 | 边说边出字（或极低延迟出字） |
| 润色 / 改写 | 标点、语病、口语杂质清理 |
| 结果交付 | 填入焦点输入框 / 复制粘贴（平台允许范围内） |
| 语言 | 至少中文、英文 |

---

## 7. 明确不做（Out of Scope）

- 会议录音、长录音库、腾讯会议体纪要  
- Agent Flow、意图分流、闹钟、PDF / PPT / 图文出件  
- 戒指连接、BLE 同步、按键手势、电脑办公控制  
- 多 Agent、工作流编排、知识库、复杂编辑器  

原则：**任何会让「说话→文字」变慢、变复杂的功能，都不做。**

---

## 8. 与 Spur Ring 的边界

| | Spur Flow | Spur Ring |
|--|-----------|-----------|
| 入口 | 主页面选「没有戒指 / Spur Flow」 | 主页面选「有戒指」 |
| 界面 | 极简页 + 悬浮窗（Android） | 现有完整 App |
| 能力 | 仅语音 → 可用文字 | 录音、纪要、Agent、出件、设备等 |

- 没戒指的人用 Flow 获客；有戒指的人走 Ring，不经过 Flow 功能堆叠。  
- 底层转写 / 润色可同源；**产品表面互不掺功能**。  
- Flow 用户日后购戒指，可从主页面改走 Ring（账号策略另定）。

|------|--------|

胜负手：同一件事，更快、更稳、中文场景更好用。

---

## 10. 非目标

- 不做「全功能 Spur App 的阉割版」挂在 Flow 名下  
- 不做会议 / Agent 的轻量入口再慢慢加功能  
- 不把 Flow 当成 Ring 的试用壳塞满硬件功能
