# 免登录公开内容研究：源码核对与实际验证

日期：2026年11月06日。

用户目标：不要求用户登录各内容平台，先拿到一些可分析的公开数据。本轮只核对本地源码及运行隔离CLI，没有改动生产服务。

## Agent-Reach

- agent_reach/runtime/public_web.py：以平台域名限定的搜索交给WebChannel，标记search_results/page_text和completeness_verified=false。
- agent_reach/channels/web.py：搜索使用Exa托管MCP；正文使用Jina Reader或Exa。当前代码无平台用户登录依赖，但仍依赖外部服务的网络、收录与配额。
- runtime/dispatch.py：未启用站内渠道时可先尝试public-web；显式--backend public-web强制只使用公开网页路径，不回退到站内浏览器。
- 已核实小红书search/read、X search等部分动作声明public_web；不是所有平台与动作都有该路径。小红书comments不走这条免登录搜索路径。

## 实测

隔离HOME与之前Agent-Reach虚拟环境保持一致，未导入Cookie、OAuth或平台账号。

`agent-reach xiaohongshu search "AI硬件" --limit 3 --backend public-web --timeout 20`

2.24秒返回ok=true，backend=public-web，3条结果。含Looki硬件相关招聘笔记及2个用户主页，文本约498/961/1321字符；发布日期均为空。说明可免登录获取部分小红书公开收录信息，但相关性参差，不能称为最近一月热门笔记或评论分析结果。原始结果见xiaohongshu.json。

`agent-reach twitter search "AI hardware" --limit 3 --backend public-web --timeout 20`

1.77秒返回UPSTREAM_BROKEN，指定平台范围内无可用结果。不能据此判断X全部内容必须登录，也不能宣称该查询免登录成功。原始结果见twitter.json。

## MediaCrawler

- 小红书、抖音等core.start在search前执行登录态检查，失败进入登录流程；未找到与Agent-Reach public-web等价的统一外部搜索回退。
- 小红书client.get_note_by_id_from_html(enable_cookie=False)默认删除Cookie请求已知内容HTML，但仍需要note_id、xsec_token等参数，且无法保证获取成功。这不是完整的免登录搜索/评论能力。
- 因此不能称所有代码都必须登录；也不能据少量免Cookie读取路径推断跨平台全面免登录。

## 产品建议

默认公共研究采用搜索引擎收录、公开页面及可用元数据；按证据标明索引摘要/正文/评论，不将缺失数据补成结论。需要自有账号经营数据时才请求OAuth。需要更深平台数据时明确说明缺口，另行评估授权或有明确数据使用权限的服务。用户免登录不等于后台无服务成本、无凭据或可完整读取平台。
