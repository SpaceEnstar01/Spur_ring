## 1. 开篇

我们的目标不是做一个更聪明的 App，而是让 AI 长在人身上。

一枚戒指，成为每个人接入智能体时代的第一入口。  
让每个人随身携带一个可行动的智能体——**想法一出口，世界就开始执行。**

想到，就记下；说完，就做成。

AI 不该住在 App 里，而该住在你身上。戒指是人类接入 AI 的第一枚「身体开关」。

## 2. 两个核心

### 第一核：入口（个人智能的身体和感官）

不是「再做一个智能戒指」，也不是缩小版录音笔。

灵感有三个特点：出现突然、消失迅速、难以预测。掏出手机、解锁、找 App，思考已经被打断，句子已经散了。

戒指成立的根本理由只有一句：**当灵感出现时，记录入口已经在手上。**

产品本质是四件事叠在同一枚硬件上：

灵感捕捉器 · 穿戴式录音入口 · AI 内容整理 · AI Agent 的随身语音入口。

戒指负责：随身佩戴、即时触发、拾音、本地缓存、状态可见。  
App 与系统负责：同步、转写、整理、检索、分流、出件。  
智能体负责：把记下的东西继续做成——提纲、纪要、待办、文档、经授权的下一步。

本产品是：戴在手上的 **AI 灵感与行动入口**。  
本产品不是：隐蔽监听、专业采访笔、健康戒指、戒指耳机、全天候偷录设备、手上跑大模型的计算器。

记录 → 理解 → 行动。最低摩擦的声音入口，接到可检索、可行动的个人记忆。

### 第二核：自建 Harness = 下一代智能操作系统（Intent OS）

不是套一层 ChatGPT，也不是给别人的 Agent 加一枚麦克风。

今天的操作系统吃点击和打字；下一步吃的是 **意图**。  
Spur 做的是 Intent OS 的硬件启动键：人随时能说 → 系统知道去哪 → 多端做完 → 成果回到自己的收口。

相对 Wispr / Typeless / WorkBuddy 这类纯软件：它们只能做屏幕上的输入。  
我们用硬件入口统领软件能力——文本润色只是整套体系里的一层基础功能，不是产品本身。

四道门槛（对投资人讲「为什么抄不走」）：

1. **硬件触发**：锁屏、口袋、走路，按一下就能说。屏幕和键盘复刻不了这个入口。  
2. **跨端调度**：戒指 → 手机 App →（下一拍）PC/Mac。不是只吐字。  
3. **语义分流**：同一句输入，自动走三条路——填入聊天 / 手机交付物（纪要、PDF、图） / 电脑重活（PPT、长稿）。  
4. **软硬协同**：低功耗常连、账号互联、高危操作二次确认。整包体验难抄。

模型会越来越便宜、可替换。真正留下的是 **操作系统 + 个人轨迹**。  
录音戒指是入口，Harness 是座舱和导航。谁只做硬件或只做聊天框，都会变成别人的外设。

### 2.1 投资人必问：Cursor 都有了，为什么还要自建一套？

戒指采到的是 **连续、第一手、只属于这个人的声音记忆**。这条数据必须在自己内部闭环：采集 → 理解 → 分流 → 出件 → 再改，飞轮才转在 Spur 上。

如果只做「Cursor / Codex / WorkBuddy 的麦克风」，数据进别人的智能体，记忆和改稿轨迹沉淀在别人家里。我们变成外设，入口没有系统，系统没有入口。

所以不是去做这个时期的第二个 Cursor，也不是去做一个戒指壳套别人的 Agent。

- Cursor / Codex：给 **代码仓库** 用的智能系统，输入是文件和终端。  
- WorkBuddy / Typeless：给 **已经坐在屏幕前的人** 用的智能系统，输入是键盘和桌面。  
- Spur Harness：给 **身上正在发生的生活和工作** 用的智能系统，输入是戒指里的私人声音。

自建 Harness，是因为 **数据闭环要求操作系统必须是自己的**。模型可以调用外面的；记忆、工具轨迹、办公载荷不能外包。赛道相邻，输入和闭环不是同一件事。

产品定义里写过「连接 Codex / OpenClaw」：那是 **能力可以对接**，不是把闭环交给对方。对接谁，由用户授权；记什么、改什么、出什么件，必须落在自己的中间层。

## 3. 超前判断（点到为止，不编造营收）

- 下一代计算的默认输入，会从「掏出手机打字」变成「身上已有的采集」。戒指是第一枚身体开关，不是苹果表的缩小版。
- 录音产品走完三阶段：保存声音（过去）→ 理解内容（现在，市场停在这里）→ **推动行动**（我们要做的第三阶段）。转写纪要已经商品化；缺的是执行闭环。
- Agent 会商品化；稀缺的是 **带着你一生上下文的操作系统**，以及「意图」这条新输入。
- 办公文档不该再是打开电脑的另一步，而是声音记忆的一种 **载荷**（说完就落成 PDF / PPT；该上电脑的，分流上去）。
- 飞轮不是多调几次 API，而是每次修改都叠在上一版上，系统越用越像你。
- 入口 × 系统 × 记忆必须在一家手里。把戒指数据交给别人的 Agent，飞轮就结束了。
- 终点不是「更好的办公 App」。数字世界先打通（聊天、文档、电脑），再扩到家居、车、机器人。远景是人的 **第二神经系统**——10 页里点到，不展开成科幻册。

## 4. 世界卡在哪

人类最大的浪费，是想法蒸发。  
记不住、找不回、说了做不成。手机和聊天框打断现实。

六件具体的事（来自产品定义，slides 收成四条即可）：

1. **灵感稍纵即逝**——走路、通勤、聊完、睡前；来不及掏手机，句子就没了。  
2. **记录动作打断思考**——解锁和打字切断连续思路；语音才接近想法刚出现时的状态。  
3. **零散语音无法再用**——没有标题、分类、关联，录了等于没录。  
4. **长录音没人愿意重听**——保存解决了，理解和整理没有。  
5. **会议结论落不了地**——纪要有了，待办、发送、更新项目仍要手做。  
6. **智能体缺少随身入口**——Agent 能办事，人却必须先打开一块屏幕。

现有方案：要携带、夹持、入耳或掏手机。健康戒指不管这句话。纯软件语音工具过不了锁屏和口袋。转写总结成熟，**执行闭环仍未形成**。

## 5. 现在做成了什么（技术与产品进度）

投资人要听到的是 **已经落地的底座**，不是「计划做 App」。

| 层 | 状态 | 一句话 |
|----|------|--------|
| **硬件** | 研发完成，功能原型已有 | 按键录音、本地缓存、BLE 同步；规格目标见 `BP_v2`（≤5g、约 8 小时连续录、约 5 米会议拾音）。下一步是工程化与小批量，不是从零发明戒指。 |
| **App** | 准备上线 | 同步、转写、纪要、Agent Flow；真机已跑通云端出 PDF/PPT 并在 App 内打开。上线 = 给第一批用户戴着日常用，不是再做一个演示包。 |
| **Harness / 智能体工程** | **已经搭建完毕** | 自建运行时、技能与工具、办公出件链路在自己的系统里转。第二核不是 PPT 上的愿景，是已经在跑的操作系统雏形。 |

第一代边界（防投资人听成「什么都做」）：录音与转写、灵感整理与会议总结、经授权的 Agent 执行。第一代不做健康、播放、通话、支付、屏幕、同传、24 小时持续录音、专业远场。

下一拍（写方向，不假装已上线）：同一张卡用上一版正文 + 新意见迭代；语义分流到 PC；全局输入层（安卓悬浮窗 / iOS 键盘）。轨迹进飞轮。

首批用户（P0）：创作者、创业者 / 管理者、会议密集的产品与项目负责人。  
他们要的不是「灵感博物馆」，而是：**想法 → 假设 → 决策 → 任务 → 推进**。

## 6. 为何是现在

端侧与 LE Audio、模型 API 与工具调用、语音转写进入日常、推理成本下降。窗口是：可做 × 可卖 × 可规模化。细节数字仍引用 `BP_v2` / 公开源，不当新 BP 的第一章。

口答一句：市场把用户教育在「第二阶段」（会转写、会纪要）；窗口是谁先把 **第三阶段（推动行动）** 和 **手上的入口** 做成一件事。

---

## 7. 越用越强（飞轮怎么转）

两层不要混：

1. **产品迭代（要做）：** 第二次改 PDF / 纪要，带着上一版正文和用户改法，在同一张卡上改。  
2. **数据飞轮（系统变聪明）：** 把「旧稿 / 改法 / 是否被接受」沉淀进 Harness，以后写类似东西能用上。云端模型 API 本身不会因为多调几次就变聪明。

壁垒不靠自训基础大模型。外购 ASR 与通用模型；**必须自己掌握中间层**：灵感整理、会议模板、路由、评测、权限与记忆。长期壁垒是：最懂戒指录音场景的数据、评测，以及行动工作流。

北极星（内部，不上 10 页主句）：每位活跃用户每周 **成功记录并再次使用** 的灵感 / 重要内容，以及用入口驱动 Agent 的次数。

## 8. 这轮融资：钱干什么

正式 BP **先不写具体融资金额、估值和股份**（内部量级：约 2000 万人民币 / 近 300 万美元，与旧版 `BP_v2` 的 $1.2M 脱钩，定稿前再填）。

本轮要验证的三件事：① 用户是否愿意买、愿意戴 ② 能否量产并稳定交付 ③ Agent 入口是不是真需求。周期仍可按约 8–12 个月讲任务，不绑定金额。

### 8.1 资金用途（写进 BP 的主表）

钱不是「维持公司」，而是把 **入口做稳、系统做真、让第一批人每天戴着**。投资人页只写用途，不写融多少：

1. **戒指工程化与小批量交付（最大头）**  
   EVT → DVT → PVT；锁核心料与供应商；可靠性 / 续航 / 连接；约 **1,000 枚** 小批量，用来验证良率和真实佩戴。没有稳定入口，Harness 只是演示。

2. **Harness / App / 云（第二核做成日常能用的 OS）**  
   Agent 运行时、技能与工具、办公出件（PDF/PPT 等）、同步与个人记忆、部署与安全。这是「下一代智能系统」本身，不是戒指的附属页面。

3. **知识产权、认证、合规**  
   能卖、能进渠道、能给机构看的产品，而不是实验室原型。录音状态必须可见；不提供隐蔽模式。

4. **用研、众筹与 α 用户**  
   第一批高频用户是否真的每天用；用他们的改稿和纠错，启动飞轮的第一圈。

工程时间轴可作附图（不跟金额绑在一起）：第 1–2 月 EVT → 第 3–5 月 DVT → 第 6–8 月 PVT 及约 1,000 枚 → 第 8–12 月交付与迭代。`BP_v2` 里的 $1.2M / 15% 股份 **不要**抄进新正文。

### 8.2 本轮先不把这些当主线

`BP_v2` 的三年销量与收入表、`产品定义.pdf` 的 1199 / $249–299 与订阅档：口答或附录。新 10 页里用下面的 **1 / 3 / 5 年阶段愿景**，不把现金流当目录。

## 9. 一年 / 三年 / 五年（SpaceX 式阶段目标）

每一档回答：**这一阶段结束时，我们打造了什么**。不写「收入做到 x」。

### 1 年：入口能戴出去，系统能天天用

我们打造了 **可小批量交付的录音戒指 + 能上线的 App + 已在跑的 Harness**。  
约 1,000 枚级验证佩戴与同步；α 用户「想到就记下、说完就做成」跑通两条闭环（灵感→方案→执行；会议→纪要→待办）；EVT / DVT / PVT 走完。证明这不是实验室演示，也不是停在第二阶段的又一个转写盒。

### 3 年：随身智能体成为一小群人的默认工作方式

我们打造了 **被一小群人每天戴着的入口，和真正用起来的个人 Intent OS**。  
采集—理解—分流—出件（纪要 / PDF / PPT / 待办，该上电脑的上电脑）是日常，不是功能清单；同卡迭代和记忆转第一圈飞轮。锁屏和口袋里能注入意图。投资人能指着真实使用，而不是架构图。

### 5 年：交卷「有身体的个人智能」

我们打造了 **个人智能离开聊天框、长在手上的完整形态**：自己的感官（戒指）、自己的操作系统（Harness）、自己的记忆与轨迹。  
模型可以换；入口和系统还在。戒指成为人机之间的标准意图接口——像触屏之于计算。  
这一阶段的愿景算交卷：不是殖民火星那种终局，而是 **「个人 Agent 第一次有身体、有操作系统」被做出来**。再往后的家居、车、第二神经系统，是下一阶段的故事。
