## 一、已经对齐的部署方向

1. Spur 目标是具备通用执行能力的 Mobile-first Personal Agent；先通过网页验证，再接回手机 App。
2. 所有新增适配与记录位于 `/Users/x/X/space/spur/V2`；原工程不移动、不覆盖。
3. 最新部署方向是优先复用队友现有的阿里云 ACK 集群，暂不购买独立 ECS，不进入节点手工安装依赖。此前讨论过独立 ECS，该方案目前暂缓。
4. 先在 Mac 构建 Linux AMD64 镜像并测试，未来上传镜像仓库，再由 ACK 的 Deployment 调度运行。
5. ACK 的实际剩余可分配资源、命名空间配额及部署权限仍需核实，不能从低 CPU 实时使用率推断资源一定足够。
6. 当前只容器化已接通的 Spur 执行链；不处理 NanoMuse、OpenClaw 和 Super-agent Prototype，也不启动 Java 后端。
7. 未获授权前不推送镜像；本轮没有操作 ACK、ECS 或线上服务。

## 二、实际执行链和依赖

```text
浏览器 / 后续手机 App
  → Node.js HTTP 后端 V2/web/server.mjs
  → DSH Headless 子进程
  → Playwright MCP（stdio）及公开网络访问代理
  → Python 研究辅助脚本、文件工具、模型/媒体 API

邮件由 Node.js 后端对接 AgentMail，发送保留单独的用户确认流程。
```

首轮镜像包含 Node.js、DSH、Playwright MCP、Chrome、Python 和当前已接入工具；不需要 Java、MySQL、GPU 或原音频服务使用的 Bun。

## 六、当前阻塞：容器访问硅基流动的 TLS 连接被重置

真实 HTTP 任务返回 502，DSH 提示 `TRANSPORT: Connection error.`；底层 Node fetch 报 TLS 建连前 `ECONNRESET`，容器 curl 也失败。

对照检查中，Mac 的 curl 和 Node 可访问硅基流动；同一 Key 调用模型列表接口返回 HTTP 200。尝试容器直连、本机已有代理和不同解析地址仍未解决。

目前只能确认存在 Mac 与 Docker 容器的出站路径差异，**尚未定位具体 VPN、防火墙、Docker 网络或其他策略原因**。没有修改全局网络配置、硬编码服务 IP、关闭 TLS 校验，或替换模型/核心依赖来掩盖问题。

结论：镜像构建与基础执行链验证已完成，但真实模型闭环尚未通过，当前不能直接标记为 ACK 部署就绪。

## 八、接续操作命令

先进入主工程：

```bash
cd /Users/x/X/space/spur
```

重新构建：

```bash
docker buildx build --platform linux/amd64 --load -t spur-agent:dev -f V2/agent/deploy/docker/Dockerfile V2
```

准备持久卷：

```bash
docker volume create spur-agent-runtime
```

运行时提供私密配置，先仅绑定本机端口：

```bash
docker run -d --name spur-agent-local --platform linux/amd64 --shm-size=1g --security-opt seccomp=V2/agent/deploy/docker/seccomp-playwright.json --env-file V2/agent/config/siliconflow.env -p 127.0.0.1:4183:4173 -v spur-agent-runtime:/opt/spur/V2/web/.runtime spur-agent:dev
```

Docker env-file 不进行 `${VAR}` 替换，也不会按 shell 方式剥除引号。如现有文件不符合格式，使用 agent.env.example 生成被 Git 忽略的 agent.env，并相应替换命令中的 env 文件路径；不要打印、提交或打包真实凭据。

运行时冒烟：

```bash
docker exec -i spur-agent-local node < V2/agent/deploy/docker/smoke.cjs
```

模拟模型闭环验证，不调用付费 API：

```bash
docker run --rm -i --platform linux/amd64 --shm-size=1g --security-opt seccomp=V2/agent/deploy/docker/seccomp-playwright.json spur-agent:dev node < V2/agent/deploy/docker/offline-loop-smoke.cjs
```
